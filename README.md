# Skillra AI Privacy Policy (static site)

A small, responsive, static privacy-policy website intended for deployment as a Render Static Site.

## Files

- `index.html` — policy content and page structure
- `style.css` — responsive styling
- `script.js` — current year and active section navigation

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Deploy to Render

1. Push this folder to a GitHub repository, for example `skillra-privacy-policy`.
2. In Render, choose **New → Static Site** and connect the repository.
3. Set the branch to `main` (or your actual branch).
4. Leave **Build Command** empty.
5. Set **Publish Directory** to `.`.
6. Deploy and test the public HTTPS URL in an incognito browser.

## Mandatory publication checklist

This is a starter template, not a verified legal policy. Before publishing:

- Replace every `[INSERT ...]` and `[ADD ...]` placeholder.
- Confirm the legal data-controller name and privacy contact details.
- Verify every category of personal/device data against the production app and all SDKs.
- List the actual authentication, database, hosting, AI, voice, analytics, crash-reporting and notification providers that receive data.
- Confirm what prompts, conversation history, files, images or audio are sent to external providers, their retention terms, and model-training settings.
- Add the real in-app account-deletion path, web deletion-request path, and deletion timeline.
- Confirm the app's target age group and children's privacy position.
- Confirm retention periods, international transfers and legal bases/rights applicable to your users.
- Ensure the app's Data safety form and this policy accurately match the same production data practices.
- Test every link and verify the policy is public, globally accessible, HTTPS-enabled and does not require sign-in.

Do not publish with placeholders. This template does not constitute legal advice.
